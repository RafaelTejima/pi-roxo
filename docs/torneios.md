# página de tornios disponiveis
Esta é a página de torneios que estarao disponiveis para ingressar.

- ## instruções
    - essa página deve ter 4 cards um do lado do outro com os torneios disponiveis para ingressar
    - os cards devem ser do tipo hero
    - o card deve conter: nome do torneio, horário e data do torneio, times inscritos, valor do prêmio, regras do torneio (drop menu).
    - o card deve ser clicavel e abrir uma página com os detalhes do torneio
    - o botao de regras deve ser um dropmenu, que mostra as regras que foram criadas na pagina de criação de torneio.
