# Tela de Cadastro e Login
O site precisa ter uma página que contenha duas áreas:
- Área de cadastro
- Área de login

## Preferência por layout
- O fundo precisa ser um carousel com no máximo 4 imagens.
    - Essas imagens precisam mudar a cada 5 segundos em loop
    - As imagens precisam ter uma transição suave de esmaecimento
-  O formulário precisa ser um card com informações de cadastro.
    - O card precisa ter tamanho médio, centralizado na tela
- O formulário deve ter campos para:
    - Nome completo
    - Nome de usuário
    - Email
    - Senha
    - Confirmação de senha
- Em baixo do botão de cadastro **precisa** ter um texto que redirecione para a área de login. Esse texto deve ser clicável e ter o formato **"Já tem uma conta? Faça login"**
