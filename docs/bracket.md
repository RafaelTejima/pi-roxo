# Sistema de Criação de Bracket
O sistema de bracket será um sistema em formato de árvore onde os jogadores competirão em partidas eliminatórias. O sistema deve se adaptar ao número de jogadores, deve especificar seus nomes, avatares e times. Esse sistema será definido pelo host do torneio logo após a criação do mesmo. O host poderá alterar as configurações do torneio até o momento em que as partidas começarem a ser jogadas.

## Como funciona?
O host do torneio poderá definir algumas configurações do torneio. Entre elas:
- Nome do torneio
- Descrição do torneio
- Tipo de bracket
- Número de times (máximo de 16)
- Tipo de jogo
- Tipo de mapa

## Tipo de Bracket
Existem 3 tipos de bracket que os organizadores do torneio podem escolher. Entre eles:
- Eliminação Simples
- Eliminação Dupla
- Todos contra todos (Free for All)
