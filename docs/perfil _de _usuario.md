
# página de perfil de usuario:

 - **avatar de usuario**
    - ele deve estar para o lado esquerdo da tela
    - no avatar deve ter um ofot de perfil (coloque um placeholder)
    - abaixo deve ter informaçoes
        -- nome 
        -- time afiliado
        -- status (online ou offlne)

 - **botoes**
    - redireciona e foca na area de perfil (para navegar até os detalhes da conta)
    
 -**logout**
  - com tratamento javascript para confirmação e executa a função de encerramento da sessão.
