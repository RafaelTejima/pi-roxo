# Página de Criação de Torneio
Esta é a página de criação de torneios.

## Instruções
- **Crie um navbar**
    - Imagem de logo no canto esquerdo (use um placeholder)
    - No centro links para as páginas: criar torneio, ranking, minha conta e sair
    - Não direcione para lugar algum por enquanto 
    
- **Crie um formulario**
    - O formulario deve ter os seguintes campos:
        - Nome do torneio
        - Horário e data do torneio
        - regras do torneio
        - Valor do prêmio 
        - Botão de enviar

- **regras do torneio**
    - as regras devem ser expostas em forma de DropDown, deve abrir uma lista para escrever as regras
    - as regras devem ser feitas antes do envio do formulario
    - não pode enviar o formulario sem regras
